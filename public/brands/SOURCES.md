# Brand assets

Glyph, Fedup Studio, Musiclb, File Studio and the personal profile captures were recovered unchanged from the last saved portfolio preview. Their original sources were each product's own website and the supplied public profiles. No product UI or profile statistics were generated.

Proofline's icon is the owner's existing `src/app/icon.svg` from sumitttt4/proofline, read on 25 October 2026. It links to a local early-build project note because a public product destination was not verified.

Duo artwork is an existing official Duolingo design-blog illustration, not a capture of the user's profile. It is presented with the user's real handle, without statistics.

React, Next.js, TypeScript, Tailwind, Figma and the other tool marks reuse the repository's existing SVG assets and provenance in `public/logos/SOURCES.md`.

Glyph-Skill’s real SVG icon was downloaded from the icon link in its own site head on 25 October 2026. GitHub’s public repository API reported 12 stars on that date; `src/data/glyph-skill.json` stores this dated snapshot, not a live counter.
